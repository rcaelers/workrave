# Pre-generated RPC test bindings

These files are generated by `clang-rpc-gen` and are checked in so the RPC
tests can be built without Rust or libclang. Do not edit them manually.

To refresh them, configure with `-DRPC_CODEGEN=ON` and build the
`rpc_refresh_pregenerated` target. CMake verifies the adjacent `.sha256`
files before using this fallback.
